## English

**ShopSphere** is a fast, Persian (RTL) e-commerce storefront and live admin dashboard built with **Next.js**, **TypeScript**, and **Tailwind CSS v4**. Everything syncs live in the browser via `localStorage` with zero external image links.

### Main Features
- **Live Storefront & Admin Sync:** Edit products or place orders and see updates instantly everywhere.
- **Smart Local Chatbot:** Suggests products, adds to cart, and tracks your latest order (ready for n8n).
- **Live Search & Wishlist:** Instant Persian search, persistent cart, and favorites drawer.
- **Dark Mode:** Custom midnight-purple theme across all pages.
- **Static & Fast:** Bundled local images and automated deployment on GitHub Pages.

### Tech Stack
Next.js (App Router) · TypeScript · Tailwind CSS v4 · React Context · GitHub Actions

### Run Locally
```bash
git clone [https://github.com/b0rhandev/shopsphere.git](https://github.com/b0rhandev/shopsphere.git)
cd shopsphere
npm install
npm run dev
```

## فارسی

**ShopSphere** یک فروشگاه آنلاین فارسی (راست‌چین) همراه با پنل مدیریت زنده است که با **Next.js**، **TypeScript** و **Tailwind CSS v4** ساخته شده. همه‌چیز به‌صورت زنده با `localStorage` هماهنگ می‌شود و تمام تصاویر داخل خود پروژه ذخیره شده‌اند.

### امکانات اصلی
- **همگام‌سازی زنده فروشگاه و پنل ادمین:** هر سفارش یا تغییر محصول در لحظه همه‌جا اعمال می‌شود.
- **چت‌بات هوشمند محلی:** پیشنهاد محصول، افزودن به سبد خرید و پیگیری زنده سفارش (آماده اتصال به n8n).
- **جستجوی زنده و علاقه‌مندی‌ها:** سرچ فوری فارسی، سبد خرید ماندگار و لیست علاقه‌مندی‌ها.
- **دارک‌مود اختصاصی:** تم شب بنفش هماهنگ در کل سایت و پنل مدیریت.
- **سرعت بالا و انتشار خودکار:** بدون وابستگی به لینک خارجی و مستقر شده روی GitHub Pages.
